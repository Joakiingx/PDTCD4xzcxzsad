# Contexto de trabajo del proyecto D4

Empieza por [contexto para IA](Notas/00-Contexto-para-IA.md), [README](README.md) y [pendientes](Notas/19-Registro-de-pendientes.md). Consulta el [registro de fuentes](Notas/04-Evidencias-y-fuentes.md) antes de reutilizar una cifra.

- D4 es el código vigente. Conserva D3 únicamente cuando aparezca en el nombre o título original de un respaldo histórico.
- Sustenta afirmaciones técnicas con la fuente local o externa correspondiente. Marca el estado como observado, declarado, estimado, hipótesis, requisito, meta o pendiente. Mantén separados estos estados al resumir.
- Registra cada nueva decisión con su fecha, responsable, evidencia y consecuencia. Mantén identificables el documento original y la versión vigente.
- La Evaluación 1 cerró en clases. Trata la Eval. 2 como desarrollo de la propuesta y el formato de Eval. 3 como pendiente de pauta oficial.
- Mantén fotos, videos, planillas, planos, registros de planta, archivos de Office y datos personales en el entorno local autorizado. La bóveda guarda notas y referencias. Confirma con el equipo el material que se podrá mostrar al comité.
- Mantén diferenciados monitoreo, confirmación remota y mando. El alcance base propuesto es monitoreo y confirmación. Cualquier mando o cambio de permisivos requiere acuerdo de Operaciones y DCS.

Para entregables nuevos, conecta afirmación, fuente, estado y método de verificación. Si un original es necesario y la sesión carece de acceso, identifica el archivo exacto y continúa con el conocimiento ya sintetizado donde sea suficiente.
