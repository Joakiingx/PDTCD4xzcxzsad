# Mapa del repositorio D4

El [README](../README.md) resume el estado actual. [AGENTS.md](../AGENTS.md) contiene las instrucciones de trabajo. Para retomar un aporte basta abrir la carpeta clonada o el repositorio `Joakiingx/PDTCD4xzcxzsad` e indicar el encargo.

| Ruta | Qué se consulta o actualiza |
| --- | --- |
| [Notas/](.) | Notas de trabajo por tema. Aquí se corrigen el alcance, los requisitos, las alternativas, la integración y la validación. |
| [Estudios/](../Estudios/) | Investigaciones y comparaciones de apoyo. La matriz v02 y el catálogo son cortes del 10-11-2026. La comparación que orienta la etapa está en [Alternativas](07-Alternativas.md). |
| [Evidencias/M7/Propuesta de solución M7/](../Evidencias/M7/Propuesta%20de%20soluci%C3%B3n%20M7/) | Fichas, actas, registros originales, datos derivados, fotos y expediente histórico. Usa el [índice de fuentes](04-Evidencias-y-fuentes.md) para identificar cada archivo. |
| [Evidencias/M7/Unidad-2/](../Evidencias/M7/Unidad-2/) | Pauta, actividades, anexos y [productos propios del D4](../Evidencias/M7/Unidad-2/03-Productos-D4/README.md). |
| [Evidencias/M7/Insumos/](../Evidencias/M7/Insumos/) | Material institucional de referencia. [Aplicación y límites](20-Referencias-de-modulos.md). |
| [Analisis/D4/](../Analisis/D4/) | Script de recálculo, inventario histórico y vínculo a las series derivadas desde la [auditoría de datos](24-Auditoria-de-datos-D4.md). |
| `Evidencias-locales/` | Respaldo de circulación interna en la copia local autorizada. [Ubicación y sincronización](22-Configuracion-Obsidian-y-GitHub.md). |

| Cuando cambia… | Actualiza primero… |
| --- | --- |
| Una observación de visita o un documento | [Índice de fuentes](04-Evidencias-y-fuentes.md) y la nota que interpreta el respaldo. |
| Una confirmación o un dato por obtener | La fila existente en [Pendientes](19-Registro-de-pendientes.md) y la nota técnica afectada. |
| Una decisión sobre diseño | La nota de [requisitos](06-Requisitos.md), [alternativas](07-Alternativas.md) o [integración](08-Arquitectura-DeltaV.md) que sustenta la decisión. |
| Una cifra de la línea base | [Auditoría de datos](24-Auditoria-de-datos-D4.md) y las notas que usan el resultado. |
| Un error de una entrega previa | [Expediente ES1](14-Expediente-ES1.md) y, si requiere seguimiento, el [registro de hallazgos](25-Registro-de-hallazgos-de-revision.md). |

La bitácora enlaza los cambios que afectan datos, decisiones o entregables. Los detalles quedan en la nota del tema. [Bitácora](12-Bitacora.md)
