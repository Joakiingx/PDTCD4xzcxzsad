# Proyecto de título D4

Joaquín Pinto y Kevin Leal · INACAP–Collahuasi · Módulo 7

El proyecto estudia cómo confirmar desde Sala de Control la zona de descarga del tripper de la correa 320CV025 en Puerto Patache. El diagnóstico registra una verificación presencial. La ES2 desarrolla y valida una propuesta académica a partir de ese problema. [Diagnóstico](Notas/01-Desafio-D4.md) · [Línea base](Notas/03-Linea-base.md)

## Estado del diseño

| Tema | Estado |

| Visita y operación | Joaquín sitúa la visita el 01-11-2026 y relata que el equipo vio una descarga de concentrado. Se revisaron fotogramas de los videos disponibles. Queda por identificar el archivo y momento que documenten la descarga. [Evidencia de terreno](Notas/05-Evidencia-visual.md) |

[Plano](Notas/05-Evidencia-visual.md#plano-mostrado-en-la-primera-reunión) |
